# Panel e — 30× BAM output footprint

This task renders the operational storage-footprint panel for the
reads/alignment QC figure set. It compares all three platforms under the four
matched reference-genome × aligner conditions at nominal 30× input depth.

The panel is designed as the 89-mm companion to Panel d. Panel d encodes a
bounded proportion with an annotated heatmap; Panel e encodes an absolute
quantity with zero-based horizontal bar lengths. The shared matrix structure
keeps the experimental conditions aligned without repeating the same visual
encoding.

## Run

```bash
Rscript scripts/reads_alignment_qc/panel_e_bam_footprint/panel_e_bam_footprint.R
```

## Input

- `data/alignment_qc.csv`
- Filter: `Depth == "30x"`.
- Expected selection: 3 platforms × 2 references × 2 aligners = 12 unique
  conditions.

## Evidence mapping

- Rows are BGI, ONT and HiFi; columns are grouped into GRCh38 and T2T-CHM13,
  with minimap2 followed by winnowmap in each group.
- Every cell contains a pale 0–115 GiB track and a platform-coloured bar whose
  length is the source BAM size. The common zero baseline supports direct
  absolute-size comparison across all 12 conditions.
- Every source value is printed to two decimal places. The bar supplies the
  comparison pattern; the label supplies exact lookup.
- No point, connector, aggregation, trend fit, ranking badge or duplicated
  platform legend is used.
- BAM output footprint is the file size generated by the recorded alignment,
  sorting and output workflow.

The displayed matrix directly supports three comparisons: platform separation
within each mapping condition, the minimap2–winnowmap change within a platform,
and the GRCh38–T2T-CHM13 change under a fixed platform and aligner.
