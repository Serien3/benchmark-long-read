# Panel a — nested input-depth rulers

This task renders the experimental-design panel for the reads/alignment QC
opening figure. It represents the three nested HG002 input subsets as one
spatially independent depth ruler per platform.

## Run

```bash
Rscript scripts/reads_alignment_qc/panel_a_input_depth/panel_a_input_depth.R
```

## Input

- `data/reads_qc_nanoplot_q20.csv`
- Expected matrix: three platforms × three target depths = nine unique rows.

## Evidence mapping

- Rows are BGI, ONT and HiFi; each row uses the fixed project platform colour.
- Every ruler has a pale target track extending to 50×.
- The three contiguous coloured segments terminate at the achieved 10×, 30×
  and highest-depth subset boundaries.
- Pale vertical guides identify the 10×, 30× and 50× targets.
- All nine achieved depths are printed inside their corresponding segments.
- The ONT ruler terminates at 47.768×, leaving the remaining target track
  visible through 50×.
- There are no points, trajectories, legends, jitter, aggregation or fitted
  trends.

## Outputs

Outputs are written to `figures/reads_alignment_qc/panel_a_input_depth/`:

- `approximate_input_depth.svg`
- `approximate_input_depth.pdf`
- `approximate_input_depth.tiff`
- `approximate_input_depth.png`
- `source_data_plotted.csv`
- `nested_depth_ruler_audit.csv`
- `data_filter_audit.csv`
- `render_manifest.csv`

The plot is produced at its intended compact top-row panel size of 60 × 34 mm.
No multi-panel assembly is generated by this task.
